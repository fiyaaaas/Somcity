# Somcity — mashruuc web oo FIYAAS ah



**Somcity** waa mashruuc web oo bilow ah oo ku jira kaydka mashaariicda **FIYAAS**.



## Xaaladda mashruuca

Repo-gani hadda waa bilow aad u kooban. Waxa ku jira fayl HTML meel-buuxin ah (`Intex.html`); website dhammeystiran iyo shaqooyin la adeegsan karo weli halkan laguma daabicin. Qoraalkan waa la cusboonaysiin doonaa marka mashruucu horumaro.
